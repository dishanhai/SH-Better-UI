# 音乐工作台视觉刷新

此前 PR #9 只提供通用导航组与动画 API，并没有重做音乐页。这一轮直接改变音乐页的可见排版，而不是依赖用户换主题才能看到区别。

## 可见变化

- 足够大的窗口显示标题区、说明与独立搜索栏，不再一打开就是铺满宽度的输入框。
- 空搜索/加载/错误以状态卡显示，空间充足时配原创矢量唱片图；主状态文字优先换行，附属说明与插图按空间让位。
- 宽结果区分歌曲操作、歌手与时长、喜欢操作；选中行背景与播放按钮同时反馈状态，增加行距。
- 底部改为持续可见的播放卡：48 GUI 单位唱片封面、曲名、歌手、播放/停止/歌词操作、状态、时间与独立进度条。
- 音乐页按钮使用小圆角，避免整页堆叠长胶囊。仍复用原生焦点、旁白、主题、工具提示与按钮反馈。
- 播放/暂停平滑改变封面装饰与播放卡强调；切页、搜索结果到达有短强调反馈。重复输入从当前值继续，不移动命中区，不延迟业务响应。减少动效直接使用静态状态。

唱片图是明确的默认装饰，不伪装成歌曲真实专辑封面，不新增图片下载。没有引入 Web UI 运行时。

## 业务与适配边界

未改变音源、搜索/建议、登录、凭据、歌单、喜欢、播放、暂停、停止、定位等业务调用。保留搜索文字、返回路径、分页状态和已有焦点转移。

丰富布局仅在宽度至少 360、高度至少 340 GUI 单位时启用。更窄/矮的窗口保留紧凑控制，避免账号详情按钮重叠。尺寸不足显示二维码时，已有页头继续提示放大窗口。所有位置均按 GUI 单位计算。

Forge 1.20.1 和 NeoForge 1.21.1 共享布局/状态/实现；NeoForge 26 的绘制 API 适配同步更新。

## 验证重点

- 布局矩阵覆盖宽 208/260/359/360/519/520/640/960，高 240/263/264/300/319/320/339/340/360/540。
- 检查标题/搜索分离、内容与分页/播放器不重叠、账号记住凭据与歌单按钮不重叠。
- 动效验证中断反转、重复触发、时钟倒退/极值、减少动效、销毁。
- 独立审查修复初版丰富布局在矮窗口的账号按钮重叠。
- 同时修复主分支已有的 POSIX 测试 fixture：故障注入删除临时凭据目录前需清理其 `.key`。未改真实凭据存储逻辑。

实际客户端视觉、不同字体/GUI缩放、旁白及GPU效果仍需游戏内验收；自动化构建不等价于已完成这些检查。

## 丰富布局加载失败修复

PR #11 的丰富播放器曾给原生 `UiSlider` 传入 14 GUI 单位高度，而该控件构造器要求至少 16。图库在布局阶段捕获 `IllegalArgumentException` 后显示“此预览无法加载”，并不是音源请求失败。此次修为 16，进度条仍完整位于 104 高的播放卡内，紧凑布局不变。

进度条几何现统一由 `OnlineMusicLayout.seekBar()` 提供；新增 `OnlineMusicSeekControlTest` 用实际布局构造真实 `UiSlider`，覆盖宽高阈值与偏移，而不再只测试矩形在边界内。修复前 360×340 用例可重复抛异常，修复后通过。此回归测试不代表游戏内完整页面、绘制或旁白验收。

修复验证：Forge 1.20.1 全套 `test kernelTest build` / `verifyLibraryJar` 通过（1280 测试、4 个既有在线实测条件跳过，kernel 504）；NeoForge 1.21.1 同检查通过（1292 测试、同 4 跳过，kernel 504、worker 13）。独立审查确认进度条底边仍留 6 GUI 单位；Neo26 使用相同布局且控件契约一致，但本环境未执行 Java 25 构建。未取得用户运行日志或进行游戏内整页验收，定位依据为源码调用链与修前/修后真实控件构造回归。

## 預設播放器的細節調整

這次只改預設 `OnlineMusicViewImpl`。實驗工作台開關、音源、登入、憑證與播放器後端不變。公開 `OnlineMusicLayout` 的方法與記錄簽名不變；舊 `MusicMiniPlayerLayout.stop()` 保留同一槽位，預設播放器改用 `more()`。

- 寬版側欄內縮，五個基本入口使用對齊的圖示；帳號和活動留在側欄底部，緊湊版將活動放到工具列。
- Spotify 是一個外開入口。搜尋詞存在時開 Spotify 搜尋，沒有搜尋詞時開 Made For You。原生音源由原有提供者清單決定，不加 Spotify 音源。
- 搜尋整合可聚焦的提交、輸入和清除控件。空白頁不畫「歌曲」小標題；原本空頁走非互動 `MusicStatusView`，沒有底板且傳入空圖示，不是玻璃遺漏。新的空狀態卡以次要文字顯示提示，可啟用官方 Discover 擴充入口與同一工作階段的最近搜尋（最多三筆，不寫磁碟）。
- 迷你播放器保持 64 GUI 單位高。正常版的封面、曲名及控制共用上排，時間和進度在下排；窄版保留逐排重排。播放是主操作，停止和取消載入在更多選單。內嵌容器若不支援該選單，會顯示有名稱的停止／取消動作。
- 三塊玻璃在繪製文字和控件前一次提交；無模糊與高對比走可讀的實色回退。鍵盤順序使用明確的群組，實機焦點、旁白和截圖矩陣見 `TODO.md`。
