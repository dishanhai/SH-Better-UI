# 原生液态玻璃媒体卡

此切片依赖基础玻璃套件和分段选择器，补齐三版本媒体卡 API；不是完整
液态玻璃 UI 库，也不是音源、封面下载或播放后端实现。

## 使用

```java
var glass = ShBetterUiApi.controls().glass(preferences);
var card = glass.mediaCard(new Bounds(x, y, 240, 64),
        title, artist, this::requestPlayback);
addRenderableWidget(card);
// 收到播放后端确认后更新，点击自身不会假定请求成功。
card.setPlaying(player.isPlaying());
card.setSelected(selected);
// 页面移除、重新布局前：glass.close();
```

卡片是一个原生焦点目标，支持指针释放及键盘激活，完整标题和副标题通过
提示与旁白提供。视觉内容保持有界矢量封面，不包含远程图片请求。
背景由宿主先绘制，卡片再使用既有原生光学通道，最后绘制内容。标题与
副标题的可读性遮罩同时考虑未知背景，并保留高对比/禁用采样的纯色回退。
具体 API、输入和生命周期测试以本批 PR 验收记录为准。

## 完整库的剩余范围

| 能力 | 当前状态 |
| --- | --- |
| 按钮、确认式开关、整数滑块 | 基础套件切片，三版本 |
| 单选分段控件 | 三版本真实光学切片 |
| 媒体操作卡 | 本切片，三版本；状态由宿主确认 |
| 通用面板布局、设置分组 | 既有分散实现，尚未统一到玻璃套件 |
| 确认弹窗、菜单、底部抽屉 | 旧版有成熟功能；26 存在原生确认页和私有演示，不代表完整公共 API 对等 |
| 文本输入、列表、滚动容器 | 尚未统一为玻璃套件 |
| 多表面融合、统一 GPU 合批预算 | 未在本切片新实现；沿用既有捕获/渲染资源 |

不会把 Web/CSS 的组件数量算作游戏原生完成度。Web 来源和许可研究见
[基础套件](liquid-glass-web-kit.md)，背景可读性约束见
[分段选择器](liquid-glass-segmented.md)。未来模态组件需另外验证焦点循环、
底层输入隔离、取消和恢复焦点，不能仅给普通面板换材质后宣称完成。
