# Minecraft 原生材质预览

Forge 1.20.1 和 NeoForge 1.21.1 共用开发者画廊。在游戏内默认按 F8，进入「开发配置 → 开发者面板 → 材质图库」。Unified UI Kernel 启用且材质目录可用时，图库默认显示「液态玻璃（UUK）」。内嵌空间不足时，点击「全屏预览」。点击当前样例名称打开目录，可按名称、别名、稳定 ID 或 `#标签` 查询有登记预览的材质。目录保留搜索词和页码。位于其他图库分类的材质样例可从目录直接全屏打开。

已启用 UUK 时，客户端代码可以直接用材质 ID 打开同一个画廊。已登记别名也可用于打开。调用应在客户端线程进行。

```java
var minecraft = Minecraft.getInstance();
var preview = ShBetterUiApi.settings().developerMaterialFullscreen(
        minecraft.screen, "sh_better_ui:liquid_glass");
minecraft.setScreen(preview);
```

此入口先查询 `UIApis.MATERIAL_CATALOG`，再按目录条目的 `nativePreviewId` 找到登记的 `PreviewSpec`。目录、预览登记或 UUK 不可用时会返回相应异常。`developerSampleFullscreen` 继续接受原有样例 ID 和内置短 ID。`clear_glass` 与 `frosted_glass` 打开旧毛玻璃样例。

## 液态玻璃

液态玻璃以 `UIApis.GLASS` 登记为 UUK 内建服务，对应服务 ID `sh_better_ui:glass`，可通过 `UnifiedUI.get().glass()` 访问。画廊的材质 ID 为 `sh_better_ui:liquid_glass`，画面由内核原生 Screen 渲染阶段绘制。`glass().diagnostics()` 可查看 Shader 状态、光学绘制次数及实色回退次数。

- **新折射**在原版标题全景上显示 Snell 斜边折射。点击右侧的模式按钮可切到**折射对比**或**校准图**。折射对比的左侧是旧折射，右侧是 Snell，两侧使用当前编辑目标的同一份草稿、视角与时刻。校准图使用与网页固定场景一致的原始光学模型。
- **光学调校**是新折射预览的首屏。将「透明 → 色调」滑杆左移会保留更多背景颜色，右移会增强中性色幕。模糊滑杆调节清晰与磨砂背景的混合量，扭曲滑杆调节斜边最大位移，单位为 GUI 单位，归零后停用 Snell 位移和色散。全屏可直接调整模糊半径，窄布局可在「参数」中调整。背景文字横跨玻璃上缘，拖动时可观察文字透过玻璃的变化。
- **播放**提供播放和暂停、单帧步进、时间归零、拖动帧滑杆和倍速。指针高光与全景位移或校准图色块跟随同一个模拟帧。开启减少动效后，可用帧滑杆或单帧步进查看变化。
- **参数**从材质条目的 Schema 读取可编辑字段、范围、步长和选项。当前可调透射、折射、透镜、散射、边缘高光、厚度、模糊半径、采样质量和前景明暗。用 Tab 移动焦点，使用方向键调节滑杆，按 Enter 激活按钮或循环选项。
- **对比**可以并排显示或用滑杆调节分界线。A 和 B 使用独立草稿，重放相同的背景、时刻和指针。可以切换编辑目标、互相复制或交换。差异按钮的提示与旁白列出变化字段。
- **预设**支持粘贴剪贴板中的统一 JSON、复制当前草稿为 JSON、恢复默认值及撤销上一次修改。导入先验证格式、材质和参数，再一次性替换当前侧的草稿。校验失败时会保留原值。复制出的 JSON 可在支持该材质的网页预览中导入。

草稿只保存在当前画廊会话。全屏切换和 GUI 缩放使用同一个预览场景。切换到其他样例后返回会恢复保存的值和帧位置，关闭画廊或独立全屏页时结束该会话。资源重载由 UUK 释放并重建光学资源，合法的参数草稿保留。资源不可用时画廊会显示提示。采样受当前显示偏好和客户端渲染能力约束，关闭采样时使用实色玻璃。

模糊强度沿用预设字段 `scattering`，模糊半径沿用 `blurRadius`，扭曲沿用 `refraction`。色调百分比为 `1 - transmission`。调校与进阶参数使用同一份 A/B 草稿和预设 JSON。对宽模糊使用均衡或超高质量。性能档保留单次背景取样。

第三方应使用独立命名空间登记元数据和预览，将预览登记句柄与模块生命周期绑定。通过材质目录打开的页面会检查对应元数据和预览登记的世代。撤销后，画廊停止调用该场景并释放资源，直接打开的全屏页返回父页。原有主题与背景设置沿用现有背景注册表和主题效果编辑器。通用目录路由可以打开这些效果对应的已登记样例，完整的九参数草稿、预设、时间和 A/B 控制由液态玻璃预览提供。

弹性碰撞场景可以拖动有把手的卡片，也可以聚焦「演示碰撞」按钮，用键盘在重叠和初始位置间切换。下拉刷新场景从顶部提示条开始拖动，也可以用下方的刷新按钮触发同一个请求流程。Visual Reveal 将区域模糊与贴图递进并排显示，图标动作场景可直接比较旋转、悬浮和弹跳。

## 验证入口

`DeveloperGalleryFullscreenTest` 验证完整 ID、内置短 ID 和现有画廊入口。`MaterialPreviewDraftTest` 验证校验失败后保留原值、复制、交换和撤销。`LiquidGlassFixtureTest` 验证相同帧的指针与背景可重复取样。

使用现有 `gradle/kernel-smoke.init.gradle` 运行隔离客户端。`MaterialCatalogSmoke` 从开发者面板按下材质图库，检查默认样例、全屏光学绘制、折射对比及返回焦点，并经公开 API 打开稳定 ID 和别名，检查减少动效、步进、键盘编辑，以及 GUI 缩放和资源重载后的草稿。运行目录包含全屏图 `material-gallery-liquid-glass.png` 和光学对照 `material-gallery-snell-comparison.png`。校准图在 0、800、1600 和 2400 ms 各输出一张 640×384 裁剪图与对应 JSON，可与网页的同时刻裁剪比较。`material-catalog-performance.json` 记录预热后的查询中位数、进程总 Java 堆使用量、资源重载时间和光学捕获计数。

验证外部消费示例时，可在独立运行目录的 `mods` 下放入已应用补丁的消费模组 JAR，然后为 `runClient` 加 `-PkernelSmokeMaterialConsumer`。Forge 开发客户端使用 Mojmap 原始 JAR，NeoForge 使用对应构建的 JAR。脚本会从标题页打开消费示例，等待光学绘制并验证返回。运行目录中的 `consumer-preset.json` 可用于同时检查浏览器预设导入。

人工验收可从材质图库执行。搜索 `liquid_glass` 或 `#glass`，打开全屏后用纯键盘切换分组。测试滑杆按下、拖动、放开及端点，切换并排和分界，导入非法 JSON 后确认原值仍在。切换资源包、显示语言、GUI 比例、高对比和减少动效，检查标签是否可读、焦点是否可见及返回目录后的页码。不同 GPU 和 JEI 叠层的表现需在相应环境检查。
