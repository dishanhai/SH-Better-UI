# 远程页面的信任边界

客户端以实际 Minecraft 连接作为远程页面的来源，服务端以该连接已经认证的玩家作为业务主体。通道连接 UUID、序号和页面实例 UUID 用于关联消息及丢弃过期数据。它们由连接协议维护。玩家身份来自平台连接。页面内容按不可信输入处理。

## 客户端接收

- 解码器限制帧和消息大小，按固定结构解码类型化值。Schema 进一步限制控件树、数据字段、列表、文本和嵌套深度。适配器须在客户端线程挂载或修改页面。
- 页面通过 Schema、当前控件能力及客户端授权校验后才能显示。控件和材质引用须由客户端解析。自定义控件须显式允许远程使用，退化路径保持已声明操作的语义。
- 权限以当前服务器、用途和页面类型为范围。主动打开、模态、HUD 和通知分别由客户端策略授权。服务端可以请求布局偏好，玩家控制前景抢占、HUD、通知和无障碍设置。
- 页面树在实例内固定，运行数据只修改已声明的整值字段。远程字段不能取得编辑框、焦点或滚动等本地状态。页面结束时释放实例作用域。

## 服务端操作

每次请求以平台玩家、连接、活动页面实例、页面 action ID、当前注册、实时权限、revision 和参数 Schema 为边界。接收 action 后先运行权限校验，回调返回时复查注册和会话是否仍有效。每连接串行分派业务操作，重入请求会被阻断。单连接的 action 注册有容量和释放句柄。桥接或 Loader 可以按页面 ID 注册同名 action，调用时使用当前页面的注册。

每页的 requestId 收据受容量限制并保留到实例关闭。已收录的请求可返回原结果，授权被撤回时会重新拒绝。容量用完时拒绝新请求，保证已有收据不会因为容量淘汰而再次执行业务。同一 requestId 始终代表原意图。若业务需要跨页面、重连或进程重启去重，应在业务事务中保存持久的业务操作 ID。

操作处理器使用服务端余额、库存、实体和规则验证业务前置条件，返回权威结果和可同步字段。客户端界面确认用于表达玩家意图，业务处理器仍须验证其交易规则。若处理器在提交业务后抛出异常或返回超出 Schema 的数据，协调器返回错误并保留该请求收据。业务侧负责提交边界和故障后的状态恢复。

## 真实物品

`ItemReference` 仅传递物品 ID 与显示数量。展示格、幽灵槽和真实槽语义独立。真实槽的存取与结算由平台的权威 Menu 或 Inventory 管理。缺少已验证的原生容器绑定时，能力协商拒绝真实容器开页，业务插件可以选择自己的原生菜单入口。

## 错误与日志

协议错误只携带 `UiErrorCode`。处理器错误与解码失败不会把业务字段、内部路径、令牌或堆栈回传。开发模式可采集每连接的有界协议元数据。生产集成可以读取协商状态、会话计数、无效分片及限流计数。访问连接、实例和请求 ID 的调试界面应沿用宿主的诊断权限。

回归验证覆盖分片预算、过期与重放、权限拒绝与撤销、重复 action、重入、收据容量及会话清理。原生容器拖放、物品结算、断线恢复与实际多人环境须在对应平台验证。
