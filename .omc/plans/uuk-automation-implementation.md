# UUK 自动化实施计划

用户于 2026-11-14 授权推进，并允许 agent 并行。以 `../specs/deep-interview-uuk-auto-discovery.md` 为需求基准；现有工作区改动保留，在 `codex/uuk-automation` 分支实施。

1. 核实 AE2 19.2.18 的查询、权限、异步计划、任务恢复边界，锁定依赖。
2. 实现共享 Java 17 能力目录、版本契约、纯数据与作用域撤销；测试冲突、过期引用、权限。
3. 实现服务端规则、页面/在线生命周期、持久化意图、在途协调和未知结果暂停；测试故障窗口。
4. 实现独立 Java 21 Rhino worker、有界协议、父进程监督及关闭清理；独立运行隔离测试。
5. 集成 NeoForge 服务端生命周期、AE2 适配器、已有 UUK 页面/网络及操作入口，复用既有控件和本地化。
6. 接入模板、可视化和脚本编辑，统一通过可信服务端执行；保持原界面回退。
7. 依次进行规格审查、代码质量审查、针对性测试和 NeoForge 构建；修复发现的问题。
8. 更新 TODO 与交接，分别报告源码验证、构建和实际游戏验收证据。

并行边界：capabilities / rules / script_worker / ae2_adapter 独占各自新增目录，主控负责平台入口、构建、界面接线和文档。所有任务不得回退或覆盖其他改动。

当前：上述核心、AE2 补货样板、固定节点和 JS 编辑器已经接线；NeoForge 最终构建及 Forge 共享回归通过，独立审查问题已修复。完整通用发现/界面生成、任意图编排、可靠任务重连、RSS 与真实游戏验收尚未完成。见 `docs/UUK_AUTOMATION_IMPLEMENTATION_2026-11-14.md` 和 `TODO.md`，不能将本批增量视为整份规格完成。
