# Visual icon masters

These monochrome SVGs are drawn on a 16-unit grid for readability at 16 px.
Keep outlines rounded and use negative space to distinguish status or action icons.
They contain editable geometry, not embedded images.

To edit this batch, change the SVG and run:

```sh
python scripts/render-visual-icons.py
python scripts/render-visual-icons.py --check
```

Use Python 3 and Inkscape 1.4 (the exporter used for the committed PNGs).
The byte-exact check intentionally reports changes in the exporter's output.
On Windows, if Inkscape is not on PATH, pass `--inkscape "C:\Program Files\Inkscape\bin\inkscape.exe"`.

Keep the generated PNGs under their existing resource IDs:

- `textures/gui/display/<id>.png` (16 × 16) for regular drawing.
- `textures/gui/display_64/<id>.png` (64 × 64) for high-resolution drawing and WebGL fixtures.
- The 64 px shop export also supplies `textures/gui/rich/material-shop.png`, retaining the `vmaterial-shop` markup alias.

Minecraft and the WebGL material preview continue to consume PNG textures.
No SVG parser or exporter is needed in the game, and normal Gradle builds use
the checked-in outputs. Existing resource packs can still override the PNGs.
The icon art is independent of the existing shader effects, motion, and tint.
Other textures, including screenshots, game models, and animations, are not
generated by this tool.

### Linux keycaps

Five optional visual variants use the same frame as the alphanumeric
keycaps: `key_linux_super` (original penguin glyph), `key_linux_compose`,
`key_linux_altgr`, `key_linux_sysrq`, and `key_linux_menu`.
Each has a `GraphicIcon.KEY_LINUX_*` constant and the standard 16 × 16 and
64 × 64 texture IDs listed above. These are explicit display choices, not
OS detection or changes to keyboard bindings. Existing generic keycaps are
unchanged.

Regenerate the masters with `python scripts/draw-linux-keycaps.py` before
running the icon exporter.
