Modifications by SHBUI contributors:
- Adapted Velvet Rose, Midnight Graphite, Porcelain Ink, Liquid Glass, Aurora
  Frost and Crystal palette values to
  renderer-independent UUK semantic tokens and the native theme registry.
- Added transparent root/inner material roles and native blur/radius mapping.
- Added contrast-safe text/focus roles, opaque low-cost surfaces and theme tests.
- No Skija/Skia implementation, music service code, logos, fonts, artwork or other
  third-party assets are included by this adaptation. Upstream NOTICE names its
  dependencies for attribution; it does not imply they are bundled in SHBUI.

The media-card control is newly implemented against SHBUI's native APIs, inspired
by Muonium's music-card information hierarchy, not copied widget code/assets.
This adaptation does not imply endorsement or affiliation by MuoniumPlayer.

The fluid background and glass plumbing are original native SHBUI implementations.
The upstream Skija/QPlayer/AMLL/Folia shaders and cover-processing code are not copied.

Control-center adaptation (2026-11):
- Referenced MConfigHudScreen.java and MConfigTheme.java for navigation, grouped
  setting-card hierarchy, translucent materials and theme-card presentation.
- Referenced SheetClock.java's shared reversible timeline principle; implemented
  UiLayeredMotion independently using SHBUI native Java APIs and reduced-motion
  preferences. No Skija renderer or upstream animation code is bundled.
- Native controls, keyboard navigation, responsive layout and explicit draft
  commit/cancel semantics are newly implemented for SHBUI.
- Optional Muonium compatibility controls require the separately installed
  MuoniumPlayer mod and invoke its public settings API; they do not ship its
  music/HUD/DSP/model backends or assets.

Native HUD and island interaction adaptation (2026-11):
- Referenced muonium-common HUD/island presentation and 1.21.1 HudConfig as
  feature references. Added independent SHBUI MusicApi rendering and scoped UUK
  hosting, normalized position/size editing, ambient status rotation, bounded
  notices, and a native-font marquee model.
- No upstream Skija renderer, downloaded native library, font, music backend,
  branded artwork, or compiled MuoniumPlayer artifact is included by this work.
- This increment does not claim complete HUD, island, or UI-library parity.

Native island scheduling and About increment (2026-11):
- Referenced DownloadDynamicIsland notification ordering and visible-budget
  principles; independently implemented SHBUI priority/expiry scheduling,
  native shell variants and real MusicApi state projection.
- About is an original SHBUI information page; no corresponding upstream page
  was found in the inspected reference revision. No MP identity/assets copied.

Native page adaptation (2026-11):
- Referenced MuoniumFavorites/FavoritesTree high-frequency settings and
  MConfigHudScreen theme selection patterns. Implemented independent native
  Favorites, loaded-mod metadata, Themes and Preferences pages using SHBUI
  controls, registry, settings and loader APIs.
- Favorites means local frequent settings, not an account's liked songs.
  Optional OneConfig/MuoniumConfig implementation and assets are not bundled.
